# Basic Calculator Web Application

A simple and user-friendly web-based calculator built using **HTML, CSS, and JavaScript**.  
This application performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

---

## 📌 Project Overview

The Basic Calculator project is designed to help users perform quick and accurate calculations through a clean and intuitive interface.  
It demonstrates core front-end development skills and JavaScript logic implementation.

---

## 🎯 Features

- Addition, Subtraction, Multiplication, and Division
- Clear (C) button to reset input
- Equals (=) button to calculate results
- Handles division by zero errors
- Responsive and user-friendly UI
- Button-based input handling

---

## 🛠️ Technologies Used

- **HTML** – For structuring the calculator layout  
- **CSS** – For styling and responsive design  
- **JavaScript** – For calculator logic and functionality
